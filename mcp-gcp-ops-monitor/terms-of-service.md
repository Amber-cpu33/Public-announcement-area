# MCP與GCP服務維運監測系統　服務條款

本條款適用於 Google OAuth 應用程式「MCP與GCP服務維運監測系統」。

**發布日期：2026-10-25**（版本 1.0）

---

## 一、適用範圍

本應用程式是開發者自用的維運工具，用來以唯讀方式查詢開發者自己的 Google Cloud 專案中的 BigQuery 資料。本應用程式不對外提供服務，不開放第三方登入或使用。

## 二、使用限制

- 只有開發者本人的 Google 帳號可以授權本應用程式
- 只做唯讀查詢，不修改任何資料
- 儀表板分享對象只能檢視開發者提供的彙總內容，不能透過本應用程式存取 BigQuery

## 三、第三方服務

本應用程式依賴下列服務，使用時另適用各自的條款：

- [Google Cloud 服務條款](https://cloud.google.com/terms) 與 [Google API 服務條款](https://developers.google.com/terms)
- [Anthropic 服務條款](https://www.anthropic.com/legal/consumer-terms)
